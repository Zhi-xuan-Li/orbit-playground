# ORBIT · 灵感引力场

一个由 AI Agent 创作的互动宇宙，适合 AI 研讨会现场演示。

## 玩法

- 移动指针吸引 800 颗星尘，点击释放冲击波。
- 切换星云、星环、漩涡，调整引力与配色。
- 开启 30 秒挑战，点击发光圆环捕捉灵感；最高纪录保存在本机浏览器。
- 支持触屏、键盘空格练习、暂停与 PNG 快照下载。

## 运行

直接用现代浏览器打开 `index.html`。无需安装依赖、构建或 API 密钥。

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch → main / (root) → Save。

## 技术

原生 HTML、CSS、JavaScript 与 Canvas 2D。响应式布局；支持减少动态效果系统偏好。作品以粒子物理算法运行，未调用生成式 AI 服务。

## 现场展示建议

先切换三种宇宙形态，再邀请观众挑战 30 秒，最后保存一张宇宙快照。
